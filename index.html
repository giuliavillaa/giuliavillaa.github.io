Cold diffusion for image restoration

PyTorch · U-Net · diffusion models

Bachelor thesis. Reimplementation of the Cold Diffusion framework (Bansal et al., 2022) from the paper, testing whether deterministic degradation can be inverted without stochastic noise.

Two forward operators on CelebA-HQ at 128×128: colour desaturation (T=50) and Gaussian blur (T=6, σ 0.4–2.0). A U-Net predicts the clean image from any degraded state, trained on an L1 objective; reconstruction uses the residual-correction update.

Desaturation: PSNR 38.01, SSIM 0.986. Deblurring: PSNR 28.67, SSIM 0.894, LPIPS 0.173, FID 64.02 — above both a Wiener-like filter and an OpenCV sharpening baseline on all metrics. The gap between the two operators quantifies how reconstruction quality depends on operator invertibility.

BetWise — gambling-risk classification

Python · XGBoost · SHAP · scikit-learn · imbalanced-learn

Prototype medical device software classifying self-reported online-gambling behaviour into four risk levels, following the behavioural clusters of Braverman & Shaffer (2012).

Model selection by nested cross-validation over 60 configurations of sampler, dimensionality reduction and classifier. Ensemble methods overfitted; the retained configuration is XGBoost without oversampling or dimensionality reduction, F1 ≈ 0.93.

SHAP used for per-prediction explanation and for a fairness audit across age and gender groups. The audit identified higher feature-importance magnitude for older users and wider SHAP variance for male predictions, documented in the technical file together with the mitigations. Classified as MDR Class IIa software with GDPR-compliant data handling and human-in-the-loop review.

Team project with Chiara Bosi and Leonardo Castelli. My contribution: model code, technical documentation, class presentation.

Human activity recognition with neural networks

Python · TensorFlow/Keras · scikit-learn · LIME

Seven-class classification of upper-body movements (left/right bicep, tricep and shoulder engagement, plus rest) from 2,700 frames of 132 pose landmarks — 33 keypoints × (x, y, z, visibility).

MLP with dense and dropout layers, tuned by nested cross-validation over 48 configurations, with the scaler fitted inside each outer fold. LIME used to inspect which landmarks individual predictions rely on.

Nested CV returns 100% accuracy. Inspection of the data shows each class is a single contiguous recording of roughly 386 frames, with consecutive frames ~31× closer in feature space than random pairs, so a shuffled split places near-duplicates on both sides of the train/test boundary. A temporal split gives 99.3%, still optimistic: with one session per class the dataset cannot estimate generalisation to a new subject.

Model against a majority-class baseline · precision, recall and F1 per class

Breast cancer survival classification

Python · scikit-learn · SVC · SMOTE · imbalanced-learn

Binary survival-status classification on 4,024 SEER breast cancer records. ColumnTransformer with separate imputation for numerical, nominal and ordinal features; SMOTE for the 5.5:1 class imbalance; nested cross-validation over 112 configurations of dimensionality reduction, classifier and sampler.

The dataset includes Survival Months, which is post-diagnosis outcome data rather than a predictor available when a prediction would be made. Excluding it and re-running the search gives macro F1 0.63 and, on the 123 deceased patients in the test set, precision 0.43 and recall 0.30 — 37 of 123 deaths identified.

Against a baseline that always predicts the majority class, F1 is 0.9029 versus 0.9173. The clinical variables in this dataset — stage, tumour size, node counts, receptor status, age — do not separate the classes in this formulation; the apparent performance came from the excluded feature. Reported as a negative result rather than a headline metric.

336 simulated days · herbivores against vegetation density

Planisuss — agent-based ecosystem simulation

Python · object-oriented design · NumPy · Matplotlib · Tkinter

Agent-based simulation of roughly 4,400 lines across 11 modules: a grid of land and water cells, regrowing vegetation, herbivores forming herds and predators forming prides. Each animal holds its own energy, lifespan, social attitude and inherited traits, and evaluates each day whether to move, feed, join a group or remain. Groups decide collectively by averaging member preferences.

Built on inheritance (Animal → Erbast, Carviz) with full type hints, save/load, history logging, and a configuration window for world parameters.

Population cycles emerge without being encoded: grazing depletes vegetation, the herbivore population falls, vegetation recovers. Running the simulation across five random seeds also shows that the predator population collapses within the first weeks under the default parameters and does not recover in any run.

ROC on the held-out set · feature importance ranking

Customer churn prediction

Python · XGBoost · pandas · seaborn · scikit-learn

Churn classification on 5,630 e-commerce customer records. Exploratory analysis of missingness patterns, univariate and bivariate distributions against the target, and a correlation matrix; six features dropped as uninformative, median and mode imputation for the rest, one-hot encoding for the remaining categoricals.

XGBoost tuned by grid search over 32 configurations with 3-fold cross-validation on ROC AUC. Final model: 200 estimators, depth 5, learning rate 0.1, subsample 0.8.

ROC AUC 0.991, accuracy 0.965, recall 0.853, precision 0.936 on the held-out set. Feature importance ranks tenure first, followed by whether the customer had filed a complaint — consistent with the bivariate analysis, where both separate the classes clearly.

Phase plane with nullclines and trajectories · the same system over time

Wilson–Cowan mean-field analysis

Python · NumPy · SciPy · Matplotlib · ipywidgets

Dynamical analysis of neural population activity using the Wilson–Cowan model: two coupled differential equations for the mean firing rate of an excitatory and an inhibitory population.

Nullclines computed by inverting the activation function, fixed points located numerically, stability read from the maximum real eigenvalue of the Jacobian. Parameter sweeps over synaptic weights, external input current, the inhibitory time constant and activation thresholds, rendered as stability heatmaps. Interactive sliders redraw the phase plane as parameters change.

At certain parameter values the trajectory converges to a limit cycle rather than a fixed point. The same framework is used to model seizure onset, where a small parameter shift crosses a bifurcation into a hyperexcitable regime.

Team project with Federica Latorre, Francesca Mustica and Alessandro Tesi.
