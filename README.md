# giuliavillaa.github.io

Source of my portfolio, live at **[giuliavillaa.github.io](https://giuliavillaa.github.io)**.

One hand-written `index.html` (HTML, CSS and a little canvas, no framework or build step), served by GitHub Pages from the `main` branch. The project diagrams are SVG files next to it; the photos and figures are JPG.

To add a project, copy one `<article class="proj">` block in the Projects section and put its repository name in the `REPOS` list at the bottom of the page. An empty name hides the "Read the code" link.

Giulia Villa, MSc student in Human-Centred AI at DTU, Copenhagen.
